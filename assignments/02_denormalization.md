## Description

## Task

1. Denormalization that violates **2NF**.
2. Denormalization that violates **3NF**.

> **Important:** at least one example must denormalize through **2 or more levels**
> (e.g. Invoice -> Order -> Customer).

## What to present

- [ ] Relational model **after** denormalization
- [ ] Trigger specification table (id, table, event, timing, purpose, error codes)
- [ ] Environment and statements that fire the triggers (triggers are tested directly in the DBMS)
